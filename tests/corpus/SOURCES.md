# Corpus sources

Every file here is a real HDR gain map sample pulled from an upstream project's
test data, kept small and redistributed under its original license. None were
generated by this project; `gmaudit` never writes image files.

| File | Source | License | Expected state |
|---|---|---|---|
| `small_uhdr.jpg` | [vearutop/ultrahdr testdata](https://github.com/vearutop/ultrahdr/tree/master/testdata) | MIT | `iso-jpeg` (MPF secondary + ISO 21496-1 APP2, no primary hdrgm XMP) |
| `sample_srgb.jpg` | [vearutop/ultrahdr testdata](https://github.com/vearutop/ultrahdr/tree/master/testdata) | MIT | `none` |
| `apple_gainmap_new.jpg` | [AOMediaCodec/libavif tests/data](https://github.com/AOMediaCodec/libavif/tree/main/tests/data) | BSD-2-Clause | `apple-aux` |
| `paris_exif_xmp_gainmap_bigendian.jpg` | [AOMediaCodec/libavif tests/data](https://github.com/AOMediaCodec/libavif/tree/main/tests/data) | BSD-2-Clause | `ultrahdr` |
| `colors_sdr_srgb.avif` | [AOMediaCodec/libavif tests/data](https://github.com/AOMediaCodec/libavif/tree/main/tests/data) | BSD-2-Clause | `none` |
| `seine_sdr_gainmap_notmapbrand.avif` | [AOMediaCodec/libavif tests/data](https://github.com/AOMediaCodec/libavif/tree/main/tests/data) | BSD-2-Clause | `iso-heif` |
| `apple_hdr_sample.heic` | [johncf/apple-hdr-heic tests/data](https://github.com/johncf/apple-hdr-heic/tree/master/tests/data), a real iPhone photo | MIT | `apple-aux` |

`tests/test_corpus.py` asserts every file above against its expected state.
`tests/test_download_integration.py` pulls a couple of additional pinned
files into a local cache on top of this set and skips cleanly when offline.
